# 00 · Start here

> **Not yet tested.** This lesson has been written but not yet followed from scratch by someone new. Screens on GitHub change, so names of buttons may differ a little.

**You will end with:** a free GitHub account, a place to keep your files online, and a first file you wrote yourself.
**You need:** a computer, an internet connection, an email address. No coding knowledge.

## How to read a lesson
- Each step says **what to do**, then **why**.
- Words in `code style` are things to type or click exactly as written.
- Toggles marked *Intermediate* or *Advanced* hold shorter notes if you already know the basics. Skip them if you do not.

## Step 1 · Make a GitHub account
GitHub is a website where people keep the files of a project, and where this whole site lives. It is free.
1. Go to github.com and choose **Sign up**.
2. Pick a username. It becomes part of your public web address, so choose one you are happy to be seen with. You do not have to use your real name.
3. Confirm your email when GitHub asks.

*Why:* an account is what lets you own a copy of every tool and lesson, instead of only looking at them.

## Step 2 · Make your first repository
A repository (repo) is a folder of files that GitHub remembers every version of.
1. Choose **New** (or the **+** menu, then **New repository**).
2. Name it `my-first-site`.
3. Choose **Public** and tick **Add a README file**.
4. Choose **Create repository**.

## Step 3 · Write your first file
1. In your repo choose **Add file → Create new file**.
2. Call it `hello.txt`.
3. Type: `Hello. I made this.`
4. Choose **Commit changes**, then **Commit changes** again.

*Why:* a commit is a saved snapshot with a note. You can always go back to any earlier one, which is why it is safe to experiment.

<details><summary>Intermediate / Advanced</summary>

The same thing from a terminal: `git init`, `git add hello.txt`, `git commit -m "first file"`, then `git remote add origin <url>` and `git push`. Use a personal access token or SSH key rather than your password.
</details>
